# Random Circle Creator

The **Random Circle Creator** is a beginner-friendly web project built with **HTML, CSS, and JavaScript**. It generates colorful circles with random sizes, colors, and positions each time the user clicks a button. This project demonstrates how JavaScript can dynamically create and manipulate HTML elements to build interactive web applications.

## Features
- 🎨 Generates random colors
- 🔵 Creates circles with random sizes
- 📍 Places circles at random positions on the webpage
- ⚡ Built using HTML, CSS, and JavaScript
- 🖥️ Demonstrates DOM manipulation using `createElement()` and `appendChild()`
- 🎲 Uses `Math.random()` to generate unique circles every time

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)

## Learning Outcomes
- DOM Manipulation
- Event Handling
- Dynamic Element Creation
- Random Number Generation using `Math.random()`
- CSS Styling with JavaScript

## How It Works
1. Click the **Create Circle** button.
2. JavaScript creates a new `<div>` element.
3. A random size, color, and position are generated.
4. The circle is styled using CSS.
5. The circle is added to the webpage using `appendChild()`.
